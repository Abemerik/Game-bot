# 🎲 Game Bot — Telegram игровой бот
## Бот находится в процессе разработки и некоторые функции еще не доделаны

Telegram‑бот с мини‑играми (кубик, слоты), магазином, реферальной системой, промокодами и админ‑панелью. Написан на Python с использованием библиотеки `pyTelegramBotAPI`.

## ✨ Возможности

- 🎲 **Игра «Кубик»** — ставка 15 монет, выигрыш 50 монет при выпадении 6.
- 🎰 **Игра «Слоты»** — три барабана со случайными символами, выигрыш при совпадении всех трёх.
- 👥 **Реферальная система** — каждый приглашённый друг даёт 500 монет пригласившему.
- 🎫 **Промокоды** — создание промокодов с ограничением по времени и количеству использований.
- 🛒 **Магазин** — обмен донат‑валюты на монеты (в разработке).
- 👑 **Админ‑панель** — управление промокодами, назначение администраторов (постепенное внедрение).
- 📊 **Статистика профиля** — количество побед, поражений, рефералов, баланс монет.


## 🔧 Установка и запуск

1. **Клонируйте репозиторий:**

    ```bash
    git clone https://github.com/Abemerik/Game-bot.git
    cd Game-bot
    ```

2. **Создайте виртуальное окружение (рекомендуется):**

    ```bash
    python -m venv venv
    ```

    Активируйте виртуальное окружение:

    - Для Linux/macOS:
        ```bash
        source venv/bin/activate
        ```
    - Для Windows:
        ```cmd
        venv\Scripts\activate
        ```

3. **Установите зависимости:**

    ```bash
    pip install -r requirements.txt
    ```

4. **Настройте переменные окружения:**

    - Скопируйте файл `.env.example` в `.env`:
        ```bash
        cp .env.example .env
        ```
    - Отредактируйте `.env`, вставив:
        - свой токен от `@BotFather` (`TOKEN`);
        - ваш Telegram ID для прав администратора (`ADMIN_CHAT_ID`).

    Пример содержимого `.env`:
    ```env
    TOKEN=ваш_токен_бота
    ADMIN_CHAT_ID=ваш_telegram_id
    ```

5. **Запустите бота:**

    ```bash
    python main.py
    ```

## 🛠️ Используемые технологии

- Python 3.11+
- `pyTelegramBotAPI`
- SQLite3
- `python-decouple`
- `APScheduler` (для периодических задач)
